Common questions

Short answers for the issues we see most.

How do I import a bank statement?

Open Inbox, choose the account, upload a PDF/CSV, then review only the missing transactions before approving.

Why didn’t a recurring transaction post?

Check Recurring for paused/ended rules, then review failed items on the transactions board and retry if funds were short.

How do I reset my password?

Local accounts can change it under Profile → Security. OAuth accounts must use their provider’s security page.

My account is disabled

Open the chat bubble → Live support {% if account_reactivation_context %} and send: “{{ account_reactivation_context }}” {% else %} and ask for reactivation with the email you used to sign in. {% endif %}

What can the assistant do?

Show balances, last transactions, and month summary; walk you through adding a transaction; or hand off to live support. AI mode (when configured) turns plain language into those same actions.

Where do I manage Telegram or passkeys?

Open Profile — Telegram linking and security (password / passkeys) live there.
